# VoxelColorPalette

继承自：[Resource](https://docs.godotengine.org/en/stable/classes/class_resource.html)

包含 256 种 8 位格式颜色的有限列表，可快速按索引访问。

## 描述：

包含一个可通过索引快速访问的颜色列表。这对于以较小的内存占用存储彩色体素很有用。

它可以与 [VoxelMesherCubes](VoxelMesherCubes.md) 配合使用。

注意：颜色在内部以 8 位分量存储，因此 [Color](https://docs.godotengine.org/en/stable/classes/class_color.html) 使用的浮点数将取整到最接近的值。
