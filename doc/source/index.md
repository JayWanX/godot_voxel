Voxel Tools 文档
============================

Voxel Tools 是一个用于在 [Godot Engine](https://godotengine.org/) 中创建体积世界的 C++ 模块。
浏览左侧的分类开始使用吧！

- [Github 仓库](https://github.com/Voxel/godot_voxel)
- [许可证](https://github.com/Voxel/godot_voxel/blob/master/LICENSE.md)

!!! note
    免责声明：本模块是围绕体素地形进行业余实验的产物，绝非通用的万能解决方案。大量功能可用于游戏开发，但另一些部分仍有欠缺或可能发生变动，因此某些信息的细节可能尚未完善。
    它也比通常的 Godot 3D 功能更具技术性。你可能需要自行调试甚至使用 C++，因此最好具备 3D 开发的先验经验。
